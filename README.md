# 匈牙利竞品价格与促销

首页是竞品价格图鉴。顶部「促销动态」打开同站的促销看板，促销页顶部「车型报价」返回首页。两个页面各自支持 Excel 导出。解压后也可双击根目录的 `index.html` 预览随包附带的数据。

## 更新现有 Netlify 站点

1. 将压缩包解压后的**全部内容**提交到现有 Netlify 站点连接的 GitHub 仓库默认分支。确保仓库根目录有 `netlify.toml`、`netlify/functions/`、`promotions/`、`scripts/` 和 `.github/workflows/update-promotions.yml`。若仓库曾单独部署促销页面，以本包中的同名工作流替代旧工作流。
2. 在现有 Netlify 项目中确认 Production branch 指向该默认分支。构建命令为 `npm run build`，发布目录为 `public`。若现有项目已连好仓库，推送后会自动部署。复用原报价站点可继续读取原有 Netlify Blobs 价格历史。
3. 在 GitHub 的 Actions 中确认 **Update Hungarian promotions** 已启用，且仓库规则允许它把促销快照提交回默认分支。促销快照提交后，Netlify 会自动发布同一站点。
4. 部署后可在 Netlify 的 Functions 页面点 `capture-prices` → **Run now** 检查报价采集。到期才实际抓取。若要提前测试促销，可在 GitHub Actions 点 **Run workflow**，这会即时扫描并从本轮起重算 15 天。

## 自动抓取范围与周期

- **车型报价**：Netlify 每天 UTC 08:00（北京时间 16:00）检查是否到期。到期时请求全部 35 款车型对应的报价来源，页面筛选和移除车型不会改变抓取范围。结果存入当前站点的 Netlify Blobs。第一次没有历史时立即到期，之后每隔 15 天采一次。月报基准价仍可单独查看。
- **促销动态**：GitHub Actions 每天 UTC 08:17（北京时间 16:17）检查是否到期。到期扫描 Honda、Kawasaki、Suzuki、Benelli、Zontes 的全部已配置入口和扫描器识别到的活动或车型链接。沿用随包快照的下一次计划日期，两类任务可在不同日期到期。促销来源、失败保留逻辑和可选 DeepL 中文翻译见 `promotions/README.md`。
- 两项任务都在未到期时跳过外部报价和促销来源请求。部分来源不可用时，按页面显示的成功、失败和核对状态判断本轮结果。

## 报价图鉴使用说明

月报数据位于 `catalog.js`，每行一个车型记录。更新基准报价可修改 `price`（整数，HUF）、`date`（采集日期，YYYY-MM-DD）和 `url`（车型页）。图片放在 `assets/` 并填写 `image`，原图网址记录在 `imageSource`，来源页记录在 `imagePage`。登记版本待确认的照片标为「参考图」，并列明图片实际车型。改完重新发布到同一个 Netlify 项目即可让访问者看到更新。

每张卡片右上角可移除单个车型。移除只影响当前浏览器，刷新后保留。点「已移除」可单独或全部恢复。Excel 支持导出当前筛选结果或全部未移除车型。按品类、排量段、品牌排列，首列为各车型的报价日期，并列出型号及 HUF、USD、EUR 三列数值报价。建议在浏览器直接打开网站地址导出。若浏览器未自动下载，点击网页显示的「手动下载 Excel」。USD / EUR 为参考折算，根据月报已列价格反推 2026-11-18 固定换算口径（1 USD ≈ 335.886 HUF，1 EUR ≈ 368.39 HUF）。

车型卡片底部的「打开车型页」会在新标签页打开对应车型。优先采用匈牙利官网或经销商页面，也保留可识别的海外车型资料页。待补车型页会显示「暂无对应车型页」。

每组将春风车型置顶。「价格对比」可选一款春风、一款竞品和币种。第一行可在日历选择日期，并编辑同一天的两车价格。第二行只列出所选竞品有报价的日期，默认选最新一天，选择日期后自动显示该日竞品报价。本次打开页面期间，切换日期后再切回来可找回手填价格。春风目标价按「目标日期竞品价 × 基准日期春风价 ÷ 基准日期竞品价」计算。

「价格更新时间」显示每轮成功、未获取和未检查的车型数。单款未抓到报价时，「最新可用报价」继续显示上次成功报价或基准价。Honda 取匈牙利规格页最低标价，ZT368 取 368K，Voge 800DSX 取 800DSX Rally，800NK 取当地 800NK Advanced，Kawasaki Z650 取匈牙利 RedBaron 的 2026 年款新车报价，其余读取对应车型页显示的报价。报价源、注册费用和促销口径可能不同。
