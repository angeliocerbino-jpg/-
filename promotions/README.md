# 匈牙利竞品促销动态

这是匈牙利竞品项目的促销看板。打开本目录的 index.html 可查看最近一次扫描结果和导出 Excel。五个品牌卡片直接打开当地促销入口。首列为来源核对日期，HUF 是原币，USD 和 EUR 沿用竞品图鉴参考汇率。

## 扫描范围

- Honda 匈牙利促销入口及其链接的活动页。库存活动中的独立车型优惠分别列出。
- Kawasaki 的 Bajnok Motor 当地促销列表及其链接的新车优惠页，不涵盖其他经销商。
- Suzuki 匈牙利官方促销入口及其活动详情，另扫官方价目表中标为促销的车型。
- Benelli 匈牙利品牌首页所列车型页。
- Zontes 匈牙利进口商的车型列表及其链接的车型页。

范围为这些入口公开链接的页面，详情页以模板中识别到的促销为准。官网删页、站点改版或读取失败时，查看「本轮来源扫描结果」。读取部分失败时，若有上一轮快照，相关品牌缺失的旧记录会标「本轮未核对」。核对日期和活动有效期分别记录。

## 中文翻译

明确列出两档价格的优惠会直接生成中文价差摘要。新出现的其他活动若需自动翻译其匈牙利语内容，在 GitHub 仓库的 **Settings → Secrets and variables → Actions** 添加 **DEEPL_AUTH_KEY**，值为你的 DeepL API 密钥。密钥只用于 GitHub Actions，不要写进网页。没有密钥或翻译失败时，仍会列出原文，并标记待翻译。已生成的译文会复用。DeepL 的额度和费用以你的账户为准。
